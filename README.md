# Macro Deck

Projeto open source de um Macro Deck baseado no Raspberry Pi Pico (RP2040).

## Objetivos

- Firmware próprio em C++
- Comunicação USB HID
- Configuração via software desktop
- Perfis armazenados na Flash
- Suporte a macros
- Encoders rotativos
- LEDs por tecla
- Hardware open source
